# Meine Rezepte

Eine moderne Rezepteapp mit React, TypeScript, Vite und React Router.

## Starten

```bash
npm install
npm run dev
```

Die App ist anschließend unter http://localhost:5173 erreichbar.

## Enthalten

- Responsive Startseite und Rezeptübersicht
- Suche nach Rezepten
- Rezeptdetailseiten
- Favoritenverwaltung im Browser-Speicher der Sitzung
- Beispieldaten in `src/data/recipes.ts`
